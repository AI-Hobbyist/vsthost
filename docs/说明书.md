# Single VST Host 使用说明书

> **版本：Single VST Host 1.5**　|　适用平台：Windows（x86 / x64）
>
> 一个 exe = 一个插件：把宿主改名为插件同名放到插件目录，双击即自动加载出声。
> 支持 **VST2 / VST3** 插件、**ASIO / JACK2** 音频后端，内置 **ITU-R BS.1770 响度电平表** 与 MIDI 参数映射。

## 1. 简介

**Single VST Host** 是一个轻量级单插件 VST 宿主（由 VSTHost 开源版改造而来）：

- **同名自动加载**：把 exe 改名为插件同名（如 `MyEffect.dll` → `MyEffect.exe`），双击即自动加载该插件并出声；
- **单插件精简**：一次只加载 1 个插件，无多余机架/链功能；
- **双音频后端**：ASIO（低延迟专业驱动）与 JACK2（跨平台音频路由）；
- **专业电平表**：主窗口 I/O 双路 dB 表 + 独立窗口的响度分析（Momentary / Short-term / Integrated / LRA / True Peak），符合 ITU-R BS.1770 / EBU R128 等标准；
- **MIDI 支持**：MIDI 输入（设备/通道过滤）、VSTi 乐器、CC→参数映射；
- **Shell 支持**：Waves WaveShell 等 shell 插件的内部效果器直接选择；
- **托盘与全局设置**：最小化到托盘、关闭行为可配置；
- **稳定性**：插件状态 30 秒自动保存（防崩溃丢失）。

## 2. 快速开始

### 2.1 同名自动加载（推荐）

把 `vsthost.exe` **改名为插件同名**放到插件所在目录：

| 插件文件 | 宿主 exe 命名 |
|---|---|
| `MyEffect.dll` | `MyEffect.exe`（放在同目录） |
| `MyEffect.vst3`（目录或单文件） | `MyEffect.exe`（放在同目录） |
| 两者并存 | 默认加载 VST3 |

双击 `MyEffect.exe` 即自动加载插件并开始出声。

> **位数匹配**：32 位插件请用 x86 版宿主（`vsthost-x86.exe`），64 位插件用 x64 版宿主（`vsthost-x64.exe`）。位数不匹配会弹出提示。

### 2.2 拖放加载

把插件文件（`.dll` / `.vst3`）**直接拖到宿主窗口**上即可加载。

### 2.3 命令行加载

```bat
vsthost.exe "C:\path\plugin.vst3"
```

### 2.4 Shell 内部效果器（Waves WaveShell 等）

把 exe 改为 `(Shell文件名)内部效果器名.exe`，例如：

```
(WaveShell1-VST3 16.6_x64)Magma StressBox Stereo.exe
```

启动后直接加载该内部效果器；也可以在菜单 **插件 → 内部效果器** 里随时切换，选择会被记忆（`last_uid`）。

## 3. 界面与菜单

### 3.1 主窗口

- 上方为菜单栏与插件编辑器区域（插件自带界面）；
- 左右两侧为**垂直电平表**（I/O，dB 刻度 -60 ~ +12，0dB 以上红色，含峰值保持线与数值框）；
- 底部状态栏：左侧 **DSP 使用率**、右侧**通道数**（JACK 模式下显示客户端名）。

### 3.2 菜单一览

| 菜单 | 功能 |
|---|---|
| 文件 | 打开/关闭插件、另存为插件快捷方式、处理测试（1 块）、全局设置、退出 |
| 插件 | 内部效果器（Shell）、测试信号（1kHz 正弦）、MIDI 参数映射 |
| 音频 | ASIO 设备、驱动控制面板、刷新设备、ASIO 通道分配、使用 ASIO / 使用 JACK |
| 视图 | 显示电平表、峰值保持、电平表刷新频率、电平表设置、独立电平表窗口 |
| 帮助 | 关于插件、关于 vsthost |

## 4. 音频后端

### 4.1 切换后端

菜单 **音频 → 使用 ASIO / 使用 JACK**（单选项）切换；选择会被记忆（`[View] backend`）。

### 4.2 启动自动检测

首次运行未配置过后端时：
- 检测到 **JACK 服务器在运行** → 默认使用 JACK；
- 否则 → 默认使用 ASIO。

### 4.3 JACK 不可用自动回退

启用 JACK 但服务器未运行 / 缺少 `libjack64.dll`（或 `libjack.dll`）时，自动改用 ASIO 出声并提示。

### 4.4 ASIO

- 默认设备为 **FL Studio ASIO**（避免抢占其他 DAW）；
- 菜单 **音频 → ASIO 设备** 选择驱动；
- **驱动控制面板** 打开驱动的原生设置；
- **ASIO 通道分配** 配置插件通道 ↔ ASIO 通道的映射；
- 采样率 / 缓冲大小在 **文件 → 全局设置** 中配置。

### 4.5 JACK2

- 动态链接 `libjack64.dll` / `libjack.dll`（缺失时提示安装 JACK2，可访问 jackaudio.org 获取）；
- **端口随插件能力注册**：
  - 音频：`in_1..N` / `out_1..M`（N/M 由插件实际通道数决定）；
  - MIDI：`midi_in` / `midi_out`（插件支持 MIDI 时注册）；
- **客户端名 = 当前插件名**（如 `Magma StressBox Stereo_1`，多实例自动加序号保持唯一）；
- 采样率 / 块大小取自服务器，变化时自动重配；
- 服务器退出时自动停止音频；
- 状态栏显示 `DSP xx%` 与 `JACK: <客户端名>`。

## 5. 电平表与响度

### 5.1 主窗口电平表

- I/O 双路垂直表，dB 刻度 **-60 ~ +12**，0dB 以上红区；
- 峰值保持线（时长可配）+ 数值框。

### 5.2 独立电平表窗口

菜单 **视图 → 独立电平表窗口**，提供专业响度分析：

- **Momentary（瞬时响度）** / **Short-term（短期响度）** / **Integrated（综合响度）** / **LRA（响度范围）** / **True Peak（真峰值）**；
- 响度标准可选：**BS.1770-4 / EBU R128 / ATSC / 平台参考**；
- 响度源切换、参考线、真峰值上限等。

### 5.3 CSV 响度日志

- 按设定间隔把响度记录到 `loudness_YYYYMMDD_HHMMSS.csv`；
- 重置后自动开始新文件。

### 5.4 电平表设置

菜单 **视图 → 电平表设置**：刷新频率、峰值保持、静音重置、静音阈值、CSV、响度标准等（滑块 + 输入框）。

## 6. MIDI

### 6.1 MIDI 输入

**文件 → 全局设置** 中：

- 启用 MIDI 输入（winmm）；
- 选择 MIDI 设备；
- 选择通道过滤（**Omni** / 1~16）。

JACK 模式下 MIDI 输入来自 `midi_in` 端口（仅通道过滤可设）。

### 6.2 VSTi 乐器

插件支持 MIDI 输入时即为乐器模式（如钢琴音源），`midi_in` 有信号即可演奏；输入电平表自动隐藏。

### 6.3 MIDI 参数映射

菜单 **插件 → MIDI 参数映射**：把外部控制器的 **CC** 映射到插件参数（VST2 / VST3 均支持），实现用推子/旋钮实时控制插件。

## 7. 全局设置与托盘

### 7.1 全局设置

**文件 → 全局设置**：

- **关闭行为**：每次询问 / 最小化到托盘 / 完全关闭；
- **ASIO**：采样率、缓冲大小；
- **MIDI**：输入启用、设备、通道、输出启用、输出设备。

### 7.2 托盘

- **最小化到托盘**：关闭窗口时按关闭行为设置处理；
- **关闭询问**：可勾选“不再提示”；
- 托盘图标 **左键 / 双击** 恢复窗口，**右键** 弹出菜单（显示窗口 / 退出）；
- 菜单 **文件 → 退出** 直接完全关闭（与关闭按钮行为不同）。

## 8. 常见问题

**Q：双击 exe 没声音？**
检查音频后端是否启动（状态栏 DSP/通道数）、JACK 是否在运行（JACK 模式下）、插件位数是否与宿主匹配。

**Q：提示找不到 libjack64.dll？**
未安装 JACK2 或未将 JACK 安装目录加入 PATH。安装 JACK2 后重启程序。

**Q：32 位插件加载失败？**
32 位插件必须使用 x86 版宿主（`vsthost-x86.exe`）。

**Q：插件状态丢失？**
插件状态 30 秒自动保存为 `<内部效果器名>_<序号>.fxp`；意外退出后可恢复。

**Q：如何恢复被最小化到托盘的窗口？**
左键单击或双击托盘图标即可恢复。

## 9. 构建与打包（开发者）

### 9.1 环境

- Visual Studio 2022+（`vsthost.sln` / `vsthost.vcxproj`）；
- 依赖 SDK 放于 `VST\`：`vst2sdk` / `vst3sdk`（3.8.0）/ `asio`（2.3）/ `jack`（1.9.22）；
- 编译 Win32 + x64 双平台，Debug / Release。

### 9.2 编译

```powershell
& "C:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\MSBuild.exe" `
  vsthost.vcxproj /p:Configuration=Release /p:Platform=x64
& "C:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\MSBuild.exe" `
  vsthost.vcxproj /p:Configuration=Release /p:Platform=Win32
```

输出：`bin\x64\Release\vsthost.exe` / `bin\Win32\Release\vsthost.exe`。

### 9.3 打包（同名即用）

```powershell
# 单插件
.\tools\pack.ps1 -Plugin "D:\plugins\Foo.dll"
# Shell 内部效果器（生成 (Shell名)内部名.exe + .ini 直选）
.\tools\pack.ps1 -Plugin "D:\plugins\WaveShell1-VST3 16.6_x64.vst3" -Internal "Magma StressBox Stereo"
```

`pack.ps1` 会按插件位数自动选择 x64 / x86 宿主，并把本说明书一并复制到输出目录。

### 9.4 shell2vst —— 独立 Shell 拆包工具

`shell2vst.exe`（x64 / x86）是**独立命令行工具**（与 vsthost 主程序解耦），把 shell 插件（如 Waves WaveShell）拆成单个独立效果器/快捷方式，供无法扫描 shell 的 DAW 使用：

```powershell
# 生成全部：快捷方式 exe + VST2 包装器 + VST3 包装器（按声道子文件夹分类）
shell2vst.exe "D:\plugins\WaveShell1-VST3 16.6_x64.vst3" --out "D:\out"
# 只生成 VST2 包装器
shell2vst.exe "D:\plugins\WaveShell1-VST3 16.6_x64.vst3" --dll
```

参数：`--exe`（快捷方式 exe）/ `--dll`（VST2 包装器）/ `--vst3`（VST3 包装器）/ `--all`（默认全部）；
`--host <宿主exe>` 指定快捷方式 exe 模板（默认取工具同目录的 `vsthost*.exe`）；`--out <目录>` 指定输出目录。
工具所需的包装器模板 `wrapper\shell2vst2.dll` / `shell2vst3.dll` 放在工具同目录的 `wrapper\` 下。

> **shell 路径说明**：生成的 `.ini` 中 `shell=` **始终写入绝对路径**（工具与 `pack.ps1` 都会把传入的相对路径规范化）。
> - 独立包装器（`--dll` / `--vst3`）即使 `.ini` 里是相对路径也能用——包装器会按**自身 DLL 所在目录**解析（`ResolveShellPath`）；
> - 快捷方式 exe（`--exe` / `pack.ps1`）的主程序**不解析相对路径**（依赖进程工作目录，不可靠），因此一律写绝对路径。
